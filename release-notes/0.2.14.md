## 新機能

- **地震速報・緊急地震速報の音は、消音の設定でも鳴る**ようにしました。「新しい通知を検出したら音を鳴らす」がオフでも鳴り、アプリの音量は最低 80% になります。Mac 本体が消音か音量 80% 未満のときは、鳴っている間だけ 80% にして、鳴り終えたら元に戻します（途中でご自身が音量を変えた場合は戻しません）。メニューに「テスト表示（地震の音）」（⌘E）を追加しました。
- **地震情報も、睡眠時間帯にかかわらず表示して鳴らす**ようにしました。これまでは緊急地震速報だけが対象で、夜中の地震情報が朝になってから流れていました。
- **要約に使うローカル LLM を選択式に**しました（gemma3:4b／TinySwallow 1.5B／その他）。小型のモデルでも、短い要約を返せるようにしています。入っていないモデルには「未インストール」と表示します。モデルの常時先読みはやめ、使い終えて2分でメモリから外します。
- 文字サイズの上限を 60pt から 100pt に上げました。

## 修正

- **Claude アプリの「スケジュール済みタスク」などの通知で、見出しが消えていた**のを直しました。同じ本文だけが毎回流れ、重複として扱われることもありました。
- **音声サービスが応答しなくなったとき、ティッカーの表示ごと止まる**ことがあったのを直しました。音の操作を表示とは別の場所で行います。
- 通知音を、次の通知が画面に入ってきた時点で切り替えるようにしました。これまでは前の通知が流れ去るまで、前の音が鳴り続けていました。
- 取り込んだ音声をループ再生するとき、継ぎ目に約1.3秒の空白が出ていたのをなくしました。
- 配布する dmg そのものにも Developer ID の署名を付けました。

公証済み（Developer ID 署名＋Apple notarization）です。ダブルクリックでそのまま開けます。

## インストール

1. `NotificationTicker-0.2.14.dmg` をダウンロードしてマウントする
2. `NotificationTicker.app` を `Applications` へドラッグして起動する
3. `システム設定 > プライバシーとセキュリティ > アクセシビリティ` で許可する

更新する場合はアプリを終了してから上書きしてください。設定はそのまま引き継がれます。
