## 新機能

- **新しい版を自分で確かめて入れ替える**ようになりました。起動の少しあとに GitHub の最新リリースを確かめ、新しい版があれば「インストール」「あとで」「この版はとばす」から選べます。「インストール」を選ぶと、ダウンロードしたアプリの署名と版を確かめてから一度終了し、入れ替えて起動し直します。古い版はキャッシュのフォルダーに控えとして移します。
- メニューに「アップデートを確認…」を追加しました。とばした版も、ここからなら聞き直します。

公証済み（Developer ID 署名＋Apple notarization）です。ダブルクリックでそのまま開けます。

## インストール

1. `NotificationTicker-0.2.15.dmg` をダウンロードしてマウントする
2. `NotificationTicker.app` を `Applications` へドラッグして起動する
3. `システム設定 > プライバシーとセキュリティ > アクセシビリティ` で許可する

0.2.14 以前からは、アプリを終了してから上書きしてください。この版からは、次の版が出たときにアプリが案内します。設定はそのまま引き継がれます。
