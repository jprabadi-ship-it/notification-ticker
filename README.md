# Notification Ticker

macOSの通知センターをアクセシビリティ経由で監視し、通知内容を選択したディスプレイの画面端へスクロール表示するメニューバーアプリです。

## 主な機能

- 通知のアプリ名・タイトル・本文をティッカー表示
- 200文字を超える通知は先頭50文字に切り詰めて表示（読み切れない長文を流し続けない）
- 背景透明度、スクロール速度、文字サイズの調整
- インストール済みフォントから表示フォントを選択
- 文字サイズを12〜60ptで調整し、ティッカーの太さも自動調整
- 上・下・左・右の表示位置を選択（左右は縦型ティッカー）
- 接続中のディスプレイから表示先を選択
- 新しい通知を検出したときの通知音（オン／オフ、テスト再生）
- システムサウンド一覧から新着通知音を選択
- 効果音の音量をアプリ内で調整（5〜100%。すべての効果音に共通で適用）
- 任意のMP3を通知音として追加・保存・選択
- 追加したMP3のコピー先フォルダを変更可能（既定は iCloud Drive の NotificationSounds。iCloud Drive が無効な環境では ~/Library/Application Support/NotificationTicker/Sounds）
- 通知がない待機中はウィンドウを完全に非表示
- ティッカー終了時に背景ごとフェードアウト
- ティッカー非表示開始と同時に再生中の音声もフェードアウト
- ティッカー表示中は選択した通知音をループ再生
- 通知センター内の時計、曜日、気温などの情報表示を除外
- 「時計・曜日・気温ウィジェット（Widgy等）を無視」スイッチで除外を切り替え（Widgyは文字形式ではなくウィンドウ／コンテナ識別子で全体除外）
- Widgyの識別子が取得できない場合も、分割された数値・度記号・C／Fを再結合して温度を検出し、ウィンドウ全体を除外
- 赤い警告スラッシュと流れる通知線をモチーフにしたmacOSアプリアイコン
- アクセシビリティ許可済みを緑のチェックアイコンで表示
- RSS 2.0／Atomフィードの複数登録と新着見出し表示
- NHKニュースのプリセット追加、任意フィードURLの入力UI
- フィード追加時にそのフィードの最新5件を即時表示
- フィード更新間隔の選択と最新5件の手動表示
- フィードごとに効果音を割り当て（未設定なら共通の通知音。選択時に試聴）
- Claude Code の状態（Bash実行待ち・許可待ち・入力待ち・応答完了）ごとに効果音を割り当て（Clauminella などが出す通知の本文で判定）
- ニュースフィードの地震関連の見出しを除外するスイッチ（地震は気象庁の速報のみ表示）
- 音源ごとにループ再生のオン／オフを設定（既定はループ。同じ音源を使う箇所すべてに適用）
- 気象庁防災XMLを60〜65秒間隔・条件付き取得で監視し、設定した下限震度以上を津波情報付きで表示
- 表示する下限震度を震度1〜7（5弱・5強・6弱・6強を含む）から選択
- 地震速報に専用の効果音を割り当て（未設定なら共通の通知音）
- 「自分の地点の震度も表示」で、指定した市区町村・都道府県の震度を本文に追加（オン／オフ可）
- 緊急地震速報（揺れる前の予測）をWebSocketで受信し、自分の地点の予測震度と到達までの秒数を表示（オン／オフ、予測震度の下限を選択可）
- 地震フィード取得失敗時の段階的バックオフとスリープ復帰時の即時確認
- クリック透過
- 全操作スペースとフルスクリーン上への表示
- メニューバーから停止、再開、テスト表示
- 通知・RSS・地震速報をまたいで、同じ本文は24時間以内に再表示しない（アプリ再起動後も維持）
- ただし「待ち」を伝える通知は例外とし、3分の間隔を空ければ同じ本文でも再表示する
- 「ログイン時に開く」でmacOSのログイン項目へ登録
- 二重起動の防止（既に動いていれば、後から開いた方は自動で終了）
- 設定の自動保存
- 睡眠時間帯を指定し、その間は通知監視・RSS・地震速報・ティッカー・通知音を停止（23:00〜7:00など日付またぎ対応）。緊急地震速報だけは睡眠時間帯でも表示し、音も鳴らす
- ティッカーをダブルクリックすると表示と待機中メッセージを閉じ、通知音も同時にフェードアウト（クリック透過中も対応）
- 改行を含む2行以上の通知では、文字領域に合わせてティッカーの高さ（縦表示では幅）を自動調整
- 黒地の上下に赤いスラッシュ警告帯を配置した緊急速報風のテーマと、極太明朝フォント
- タイトルは赤、本文は白、時刻表現はオレンジで色分け
- 複数行通知のサイズ拡張は最大4行まで（5行目以降は4行目へ連結）
- 表示構成は「タイトル1行＋内容最大3行」。区切り項目を縦に並べる
- 各行を固定行高で上端から詰めて描画し、不要な上側余白を作らない
- フォント固有の行間余白を上下へ均等配分し、文字を垂直方向の中央へ配置

## 必要環境

- macOS 14以降
- Xcode 16以降または対応するSwiftツールチェーン
- アクセシビリティ権限

## インストール

### 配布版（.dmg）を使う

1. [リリースページ](../../releases) から `NotificationTicker-x.y.z.dmg` をダウンロードする
2. マウントして `NotificationTicker.app` を `Applications` へドラッグして起動する

v0.2.11 から Developer ID で署名し Apple の公証を受けているため、そのままダブルクリックで開けます。

起動後、次の場所でアクセシビリティを許可してください。許可しないと通知を読み取れません。

`システム設定 > プライバシーとセキュリティ > アクセシビリティ`

アプリはメニューバーに常駐します。Dock にアイコンは出ません。

### ソースからビルドする

```sh
./scripts/run-app.sh
```

ビルド成果物は `dist/NotificationTicker.app` に生成され、そのまま `/Applications/NotificationTicker.app` にインストールされます。起動と許可は必ずインストール先の `/Applications` 版に対して行ってください。

ソースツリーが iCloud Drive や Google Drive などの同期フォルダ配下にある場合、その場所のバンドルではアクセシビリティ許可が安定しません。必ず `/Applications` 側を使ってください。

署名は Developer ID（identity ベース）なので、リビルドしてもアクセシビリティ許可は維持されます。許可後にアプリが反応しない場合は、アクセシビリティ一覧の `NotificationTicker` を `−` で削除し、`/Applications/NotificationTicker.app` を `+` で再追加してください。

## 配布用の .dmg を作る

```sh
./scripts/make-dmg.sh
```

`dist/NotificationTicker-<バージョン>.dmg` が生成されます。署名は Developer ID、公証は App Store Connect の APIキー（`~/.appstoreconnect/private_keys/`）を使って自動で行われます。

## プライバシー

- 本アプリは、macOSの通知センターに表示されている内容をアクセシビリティAPI経由で読み取り、画面端に表示します。読み取った内容を外部へ送信することは一切ありません
- 通知の内容をファイルへ保存することもありません。再表示を防ぐための記録は、本文そのものではなくSHA-256のダイジェストで、24時間で破棄されます
- 設定（表示位置、効果音の割り当て、フィードURLなど）は、この端末のUserDefaultsにのみ保存されます
- ネットワーク通信は、利用者が登録したRSS/Atomフィードの取得と、気象庁の防災情報XMLの取得だけです。解析やトラッキングの類は行いません
- 通知履歴のデータベースには直接アクセスしません

## 素材について

効果音は同梱していません。macOSのシステムサウンドから選ぶか、利用者自身が用意したMP3を設定画面から追加してください。

地震情報は気象庁の防災情報XMLを利用しています。緊急地震速報は有志が運営するP2P地震情報（api.p2pquake.net）から受け取っています。

**本アプリは公式の防災情報提供手段ではありません。**緊急地震速報は予測値であり、第1報ほど精度が低く、続報で震度が変わることや取り消されることがあります。震源が近い場合は揺れが到達したあとに表示されます。配信元の可用性も保証されていません。避難などの判断は、必ず気象庁および自治体の発表と、公式の防災アプリを確認してください。

## 制約

macOSには、他アプリを含むすべての通知を取得する公開APIがありません。本アプリは通知センターのアクセシビリティ要素を読み取るため、macOSの大きな更新で調整が必要になる可能性があります。通知履歴データベースへの直接アクセスは行いません。

一部の通知は、通知プレビューを無効にしている場合やアプリ固有の表示方法によって本文を取得できないことがあります。
